# Luan Ferreira — Personal Portfolio

Personal portfolio website built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/). It features a custom **Deep Space** dark theme with pure CSS animated starfields, glassmorphism UI components, bilingual localization (English and Portuguese), and a client-side contact form powered by [EmailJS](https://www.emailjs.com/).

## Overview

- **Bilingual Support (i18n):** Native Portuguese (`/`) and English (`/en/`) routes powered by Jekyll data files (`_data/pt.yml` and `_data/en.yml`).
- **Deep Space Aesthetic:** Responsive dark mode interface with multi-layer pure CSS starfield animations and glassmorphic cards.
- **Contact Integration:** Direct client-side message delivery using the EmailJS SDK.
- **Static & Fast:** Zero heavy JavaScript dependencies, optimized for GitHub Pages.
